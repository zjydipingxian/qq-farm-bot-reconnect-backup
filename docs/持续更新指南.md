# qq-farm-bot-reconnect 持续更新指南

本文记录本项目与原项目开发分支之间的 Git 关系，便于后续持续同步和即时发布。

## 仓库关系

当前本地仓库已经配置：

```text
origin   https://github.com/zjydipingxian/qq-farm-bot-reconnect.git
upstream https://github.com/zjydipingxian/qq-farm-bot.git
```

- `origin`：你的独立仓库，用于保存和发布本项目。
- `upstream`：原项目仓库，用于读取原作者的 `dev` 分支更新。
- `master`：当前可运行版本，推送到你的仓库 `master`。
- `dev`：当前开发版本，推送到你的仓库 `dev`。
- 原项目开发分支：`upstream/dev`，只读跟踪，不直接修改。

当前自动重连功能已经提交并推送到：

```text
https://github.com/zjydipingxian/qq-farm-bot-reconnect
```

## 获取原项目最新代码

在项目根目录执行：

```powershell
git fetch upstream dev
git log --oneline --decorate --graph HEAD..upstream/dev
```

第二条命令会列出原项目新增的提交。先查看差异，再决定是否同步：

```powershell
git diff --stat HEAD..upstream/dev
git diff HEAD..upstream/dev -- core/src web/src
```

## 同步方式

### 方式一：将原项目更新合并到当前开发分支

适合希望保留当前项目提交历史的情况：

```powershell
git switch dev
git fetch upstream dev
git merge upstream/dev --no-edit
```

如果出现冲突：

```powershell
git status
# 手动处理冲突文件后
git add <已处理的文件>
git commit
```

处理完后运行验证：

```powershell
pnpm build:core
pnpm typecheck:web
pnpm -C core test
```

确认无误后推送：

```powershell
git push origin dev
```

### 方式二：只挑选原项目中的某个提交

适合单独接入一个修复：

```powershell
git switch dev
git fetch upstream dev
git log upstream/dev --oneline
git cherry-pick <原项目提交号>
```

自动重连相关文件包括：

```text
core/src/runtime/auto-reconnect.ts
core/src/runtime/runtime-engine.ts
core/src/runtime/worker-manager.ts
core/src/models/store/global-config.ts
core/src/models/store/shared-state.ts
core/src/types/config.ts
web/src/components/settings/ReconnectSettingsForm.vue
web/src/views/Settings.vue
web/src/stores/setting.ts
```

同步时如果这些文件发生冲突，应保留当前项目的自动重连配置字段和账号绑定逻辑，再吸收原项目的业务修复。

## 从开发版发布到 master

开发分支验证通过后：

```powershell
git switch master
git merge dev --no-edit
pnpm build
git push origin master
```

建议先在 `dev` 分支完成验证，再合并到 `master`，避免运行中的版本直接引入未验证改动。

## 即时更新检查

可以用下面的命令快速检查原项目是否有新提交：

```powershell
git fetch upstream dev
git log --oneline HEAD..upstream/dev
```

有输出表示原项目有尚未同步的提交；没有输出表示当前分支已经包含对应历史。

查看本地和远程状态：

```powershell
git status --short --branch
git remote -v
git branch -vv
```

## 运行数据和敏感配置

账号、登录 Code、API Token 等运行数据位于 `data/` 目录，不应提交到 Git。自动重连配置在 Web 面板中填写，默认 Code 接口为：

```text
http://211.154.25.123:28999/api/open/v1/farm/code
```

Token 不要写入源代码、README 或提交信息。服务支持 HTTPS 时，应在面板中改用 HTTPS 地址。

## 推荐更新节奏

1. `git fetch upstream dev` 获取原项目变化。
2. 查看 `git diff` 和提交记录。
3. 在 `dev` 分支合并或挑选需要的提交。
4. 执行 Core 构建、Web 类型检查和测试。
5. 推送 `origin/dev`，确认运行稳定后再合并并推送 `origin/master`。
